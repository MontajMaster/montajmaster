# MontajMaster

Здесь живёт библиотека маркировки трубопроводов (наклейки, бирки, таблички) — папка `labels/`.

- Всё, что связано с наклейками, мастер-файлами Affinity (.af), базой наклеек и печатью,
  делает агент **label-master** (`.claude/agents/label-master.md`); его правила обязательны.
- Скиллы: `label-order` (заказ по объекту → листы в типографию), `label-affinity` (разбор и
  пополнение мастер-файлов .af).
- Инструмент: `python3 labels/lk.py -h`; зависимости — `pip install -r labels/requirements.txt`.
- Файлы `.af` в `labels/affinity/` только читаются, никогда не редактируются побайтно.
- Общение и сообщения коммитов — на русском.
