# Библиотека маркировки MontajMaster

Наклейки для трубопроводов: **ГВС** (красный кант), **ХВС** (синий), **РЕЦ** (зелёный),
надписи отопления. Шаблон снят с мастер-файла Affinity Designer 3: 32×62 мм, чёрная плашка,
скругление 2,5 мм, градиентный кант, сверху помещение, по центру вертикально — потребитель.

```
pip install -r labels/requirements.txt
python3 labels/lk.py -h
```

## Быстрый старт

```bash
# разобрать и занести мастер-файлы
python3 labels/lk.py af-info "labels/affinity/КУХНЯ/ХВС КУХНЯ ПЫЛЕСОС.af" --tree
python3 labels/lk.py af-import путь/к/*.af

# новая наклейка сразу для двух контуров
python3 labels/lk.py add --circuit ГВС,ХВС --top ДЕТСКАЯ --top2 сан.узел --main РАКОВИНА

# макеты: PDF под печать, SVG для Affinity, PNG-превью
python3 labels/lk.py render --status new

# заказ по объекту -> листы под печать
python3 labels/lk.py order "labels/db/orders/ПРИМЕР-объект.csv" --sheet SRA3
```

Результаты — в `labels/out/` (не хранится в git, пересобирается командой).

## Что получает типография

- PDF, CMYK, фон — rich black 60/40/40/100, текст белый в кривых (шрифт не нужен);
- вылет 1,5 мм на каждую наклейку, зазор 4 мм;
- контур реза — плашка `CutContour` (overprint), по форме скруглённого прямоугольника;
- служебная строка на поле листа: задание, лист N/M, количество, формат, дата;
- рядом `сводка.txt` с составом тиража и PNG-превью листов.

Раскладка: A4 — 20 шт, A3 — 44, SRA3 — 48, SRA3+ — 56 (`lk.py plan`).

## Шрифт

Фирменный шрифт мастер-файла — **Buyan**. Положите `Buyan-Regular.ttf` в `labels/fonts/` —
он подхватится автоматически. Пока его нет, используется Oswald Light (OFL, лежит рядом)
— близкий по характеру узкий гротеск; для финальной печати лучше Buyan.

## Affinity

`.af` — закрытый формат: `labelkit/af.py` его **читает** (размер, DPI, шрифты, миниатюра,
дерево слоёв с видимостью и текстами), но не записывает. Новые наклейки попадают в Affinity
через SVG со слоями, названными как в мастере (`render --format svg --live-text`):
Файл → Поместить → сохранить как `.af` → `af-import`.

## Устройство

| Модуль | Назначение |
|---|---|
| `labelkit/af.py` | чтение .af |
| `labelkit/geometry.py` | контуры и текст в кривых (fontTools) |
| `labelkit/render.py` | компоновка наклейки, PDF/SVG/PNG |
| `labelkit/sheet.py` | раскладка на печатный лист |
| `labelkit/store.py` | реестр, словарь, заказы |
| `labelkit/cli.py` | команды `lk.py` |
| `config/style.json` | все размеры, цвета, форматы листов |
